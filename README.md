# NASKCOrpions team website

A static website for FIRST Robotics Competition Team 2594, built with HTML and CSS. It presents a team introduction, sponsors, and contact information.

[Published site](https://codeonwheels.github.io/naskcoWebsite/)

## Run locally

```sh
git clone https://github.com/CodeOnWheels/naskcoWebsite.git
cd naskcoWebsite
python -m http.server 8000
```

Open http://localhost:8000. No dependency installation or build step is required.

## Structure

- `index.html` — team introduction and featured sponsors.
- `pages/sponsors.html` — sponsor page.
- `pages/contact.html` — team contact information.
- `pages/history.html` — history placeholder.
- `styles.css` — shared styling.
- `images/` — team, FIRST, and sponsor assets.

## Status and attribution

This is an early team-site project with 2023 content. The history page is unfinished, and some social links are placeholders. Team contact details and sponsor information should be checked before reusing the site for current outreach.
